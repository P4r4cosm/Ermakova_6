# Ermakova_6
## Структура проекта

Проект состоит из следующих основных файлов Python:

*   `elgamal_utils.py`: Реализация криптографических примитивов Эль-Гамаля (генерация ключей, шифрование, дешифрование, подпись, проверка), генератор псевдослучайных чисел (LCG), функции для работы с простыми числами.
*   `certificate_manager.py`: Классы для создания, управления и хранения цифровых сертификатов (`Certificate`, `CertificateStore`).
*   `network_utils.py`: Функции для сетевого взаимодействия (отправка/получение JSON-сообщений, создание серверного сокета, подключение к серверу).
*   `base_node_app.py`: Базовый класс для всех узлов системы (RCA, LCA, Клиент), реализующий общий GUI и сетевую логику сервера.
*   `root_ca_app.py`: Приложение Корневого Удостоверяющего Центра (RCA). Отвечает за генерацию глобальных параметров (p, g), выпуск собственного самоподписанного сертификата и выдачу сертификатов для LCA.
*   `local_ca_app.py`: Приложение Локального Удостоверяющего Центра (LCA). Получает сертификат от RCA и выдает сертификаты клиентам в своей зоне ответственности.
*   `client_app.py`: Приложение Клиента. Получает сертификат от LCA, может обмениваться зашифрованными и подписанными сообщениями с другими клиентами.

## Подготовка к запуску

1.  **Python:** Убедитесь, что у вас установлен Python (версия 3.7 или выше).
2.  **Зависимости:** В данном проекте внешние библиотеки не используются, все реализовано с использованием стандартной библиотеки Python.
3.  **Файлы:** Все `.py` файлы должны находиться в одной директории.

## Порядок запуска и использования

**Важно:** Узлы PKI (RCA, LCA) должны быть запущены *до* того, как клиенты или другие LCA попытаются к ним подключиться. Рекомендуется запускать каждый узел в отдельном терминале/консоли.

Конфигурационные файлы и хранилища сертификатов для каждого узла будут создаваться автоматически в поддиректориях `configs` и `node_data/<node_id>/certs` соответственно.

### Шаг 1: Запуск Корневого Удостоверяющего Центра (RCA)

1.  Запустите `root_ca_app.py`:
    ```bash
    python root_ca_app.py
    ```
2.  Откроется окно "Корневой УЦ (RCA)".
3.  **Действия в RCA:**
    *   **1. Сгенерировать P и G**: Нажмите эту кнопку.
        *   При первом запуске или если хотите сменить параметры, введите желаемую разрядность для простого числа `P` (например, 64-128 для тестов, большие значения потребуют больше времени для генерации).
        *   Глобальные параметры `p` и `g` будут сгенерированы и отображены на вкладке "Ключи и Сертификат".
    *   **2. Сгенерировать ключи RCA и сертификат**: Нажмите эту кнопку *после* генерации P и G.
        *   Будут сгенерированы ключи для RCA и создан самоподписанный сертификат. Они также отобразятся на вкладке "Ключи и Сертификат".
    *   **Сохранить конфигурацию**: Рекомендуется нажать для сохранения текущих параметров (p, g, ключи, сертификат RCA) в файл `configs/RootCA_rca_config.json`.
    *   **Запустить сервер**: Нажмите эту кнопку, чтобы RCA начал принимать сетевые запросы от LCA.
        *   Будет запрошен порт сервера (по умолчанию 10000).

Теперь RCA готов к работе и ожидает запросов от LCA.

### Шаг 2: Запуск Локальных Удостоверяющих Центров (LCA)

Можно запустить один или несколько LCA. Каждый LCA должен быть запущен в отдельном терминале.

1.  Запустите `local_ca_app.py`:
    ```bash
    python local_ca_app.py
    ```
    *   При запуске будет запрошен `ID Локального УЦ` (например, `LCA1` или `LCA2`) и `Порт LCA` (например, `10001` для LCA1, `10002` для LCA2). Эти ID и порты должны быть уникальными.
2.  Откроется окно "Локальный УЦ (LCA): [ваш_ID_LCA]".
3.  **Действия в LCA:**
    *   **Укажите RCA IP и RCA Port**: По умолчанию это `127.0.0.1` и `10000`. Убедитесь, что RCA запущен и слушает на этом адресе и порту.
    *   **0. Получить параметры от RCA**: Нажмите эту кнопку.
        *   LCA подключится к RCA и получит глобальные параметры `p`, `g` и сертификат RCA. Они будут отображены на вкладке "Ключи и Сертификат". Существующие ключи и сертификат LCA (если были) будут сброшены.
    *   **1. Сгенерировать ключи LCA**: Нажмите эту кнопку *после* получения параметров от RCA.
        *   Будут сгенерированы ключи для данного LCA.
    *   **2. Запросить сертификат LCA у RCA**: Нажмите эту кнопку *после* генерации ключей LCA.
        *   LCA отправит запрос RCA на получение собственного сертификата, подписанного RCA. После успешного получения он будет отображен.
    *   **Сохранить конфигурацию**: Рекомендуется для сохранения параметров LCA, его ключей, сертификата и адреса RCA.
    *   **Запустить сервер**: Нажмите, чтобы LCA начал принимать запросы от клиентов.
        *   Будет запрошен порт сервера (тот, что вы указали при запуске LCA).

Повторите эти шаги для каждого LCA, который вы хотите запустить (например, `LCA2` на порту `10002`).

### Шаг 3: Запуск Клиентов

Можно запустить одного или нескольких клиентов. Каждый клиент должен быть запущен в отдельном терминале.

1.  Запустите `client_app.py`:
    ```bash
    python client_app.py
    ```
    *   При запуске будет запрошен `ID Клиента` (например, `client1@LCA1`, где `LCA1` - это ID LCA, к которому клиент будет обращаться) и `Порт Клиента` (например, `11001` для client1).
2.  Откроется окно "Клиент: [ваш_ID_Клиента]".
3.  **Действия Клиента:**
    *   **Укажите LCA IP и LCA Port**: Введите IP и порт того LCA, к которому приписан данный клиент (например, `127.0.0.1` и `10001` для `client1@LCA1`).
    *   **0. Получить параметры от LCA**: Нажмите эту кнопку.
        *   Клиент подключится к указанному LCA и получит параметры `p`, `g`, сертификат LCA и сертификат RCA. Они будут отображены на вкладке "Ключи и Сертификат". Существующие ключи и сертификат клиента (если были) будут сброшены.
    *   **1. Сгенерировать ключи**: Нажмите *после* получения параметров от LCA.
        *   Будут сгенерированы ключи клиента.
    *   **2. Запросить свой сертификат у LCA**: Нажмите *после* генерации ключей.
        *   Клиент запросит у своего LCA сертификат, подписанный этим LCA.
    *   **Сохранить конфигурацию**: Сохраняет параметры клиента, ключи, сертификат и адрес LCA.
    *   **Запустить сервер**: Нажмите, чтобы клиент мог принимать входящие сообщения от других клиентов.
        *   Будет запрошен порт сервера (тот, что вы указали при запуске клиента).

Повторите эти шаги для других клиентов (например, `client2@LCA1` на порту `11002` или `client3@LCA2` на порту `11003`).
